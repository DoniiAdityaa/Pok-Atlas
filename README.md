# PokéAtlas

A Pokémon exploration mobile application
built with Flutter and PokéAPI.

## Features

- Pokémon exploration
- Search Pokémon
- Pokémon detail
- Type filtering
- Generation filtering
- Pagination
- Favorites
- Pokémon comparison
- Offline caching
- Firebase authentication
- Cloud favorites

## Tech Stack

Flutter
Dart
Dio
Retrofit
Cubit
GetIt
Firebase
Firestore
PokéAPI
